Tools Reference

Every tool the ThriveStack MCP Server currently exposes, with parameters and what each one does.

The ThriveStack MCP Server currently exposes 25 tools and one prompt. They cover your brands, AI-search visibility and citations, the sources AI answers draw on, your site’s crawl and indexing health, prompt research, and content and ad recommendations.

24 of the 25 tools are read-only. The only tool that changes anything is save_content_recommendations, which saves recommendations to your brand as suggested items for your team. It cannot approve, dismiss, assign or delete anything, and your AI client asks you to confirm before it runs.

None of these tools take a project_id or similar tenant parameter. Your product and environment are resolved automatically from how you authenticated (OAuth session or Personal Access Token) — see Setup.

Your AI assistant calls these automatically based on your questions. The server also provides one prompt, ai_visibility_analyst, a ready-made content-strategy analysis — see Prompts. It does not expose any MCP resources.

Response format

There is no single universal response envelope — each tool returns the JSON shape natural to its own data. The visibility and recommendation tools return structured report objects, and check_connection returns a small fixed object.

Tools whose description says they return a “clear empty” or “no-data” result are designed to return an empty-but-valid result rather than an error when there’s nothing yet (for example, a domain that hasn’t been probed). Treat that as “nothing here yet”, not a failure. Large results are paged or capped; the tools that page accept page and page_size (or limit and offset).

Brands & Account

get_accessible_brands

Lists the brands (products) the signed-in ThriveStack account can access, with name and domain for each. These are the brands the account can switch between, and the domains the other tools accept. The result is the same whether you connect with OAuth or a personal access token.

No input parameters required.

get_brand_information

Returns the saved brand profile for a domain, as captured during AI Visibility setup and any later edits: description, value offering, industry, HQ country, business model, products and services, brand identity, customer segments, target markets, tracked competitors, tracked topics, language, monitored AI engines, buyer-intent mix, and setup progress (last_completed_step, user_edited).

ParameterTypeRequiredDescription
domainstringYesDomain to fetch the brand profile for, e.g. acme.com

Visibility & Citations

get_domain_report

Returns the visibility report for a brand's most recent completed AI-visibility probe run: overall visibility and average position, competitor and mentioned brands, broken down by topic and by tracked question, with per-AI-model detail. Use it to answer how visible a brand is and who appears alongside it.

ParameterTypeRequiredDescription
domainstringYesDomain to fetch the visibility report for

get_domain_prompts

Lists the tracked buyer questions (prompts) generated for a brand's domain, grouped by topic. Use it to see or review what is being tracked; it contains no visibility results (get_domain_report has those). The domain must have completed brand setup; otherwise the tool returns an explanatory error message.

ParameterTypeRequiredDescription
domainstringYesDomain to fetch generated prompts for

get_citation_probe_data

Returns the raw citation evidence from a brand's most recent completed AI-visibility probe run: every tracked buyer question, one record per question and AI engine.

ParameterTypeRequiredDescription
domainstringYesDomain to fetch citation probe evidence for

get_competitor_visibility

Weekly AI-search visibility % (and average rank, where available) for a domain's own brand alongside its tracked competitor brands, side by side — matching the product's AI Visibility > Competitors page. If competitor_domains isn't provided, the domain's saved tracked-competitor list is used automatically.

ParameterTypeRequiredDescription
domainstringYesDomain to fetch competitor visibility for
competitor_domainsstring[]NoOptional list of competitor domains to compare against, overriding the domain's saved tracked-competitor list. The domain itself is always included automatically.
weeksnumberNoNumber of weeks of history to return (default 8, clamped 1-52)

get_engine_visibility_trend

Daily AI-search visibility % for a domain's own brand, split by AI engine (ChatGPT, Perplexity, Gemini, ...), with average rank per engine where available. Each point is one day: 'values' maps engine id to visibility %, 'avg_ranks' maps engine id to average position (lower is better). Days appear only when a probe ran, so gaps between dates are normal.

ParameterTypeRequiredDescription
domainstringYesBrand domain, e.g. acme.com
end_datestringNoWindow end, YYYY-MM-DD (inclusive). Omit for no upper bound.
start_datestringNoWindow start, YYYY-MM-DD (inclusive). Omit for no lower bound.

Sources & Pages

get_url_report

Per-URL retrieval and citation metrics across every source URL surfaced by a domain's most recent completed AI-visibility probe run — which specific pages are getting retrieved and cited, and how often.

ParameterTypeRequiredDescription
domainstringYesDomain to fetch the URL report for
pagenumberNoPage number, 1-indexed (default 1)
page_sizenumberNoPage size (default 25, max 100)
searchstringNoFilter by substring match against URL, title, domain, URL type, or domain type

get_source_mix_summary

Where AI answers about a domain's prompts get their information, summarised over a date window — matching the panels above the product's AI Visibility > Domains and URLs tables.

ParameterTypeRequiredDescription
domainstringYesBrand domain, e.g. acme.com
end_datestringNoWindow end, YYYY-MM-DD (inclusive). Omit for no upper bound.
grainstringNoSummarise cited domains (default) or individual cited URLs One of: domain, url.
source_classstringNoOnly count sources of this class in movers and type_shares One of: owned, earned, other_cited.
source_subtypestringNoWith source_class: only that domain type, using a subtype value exactly as returned in source_mix (e.g. Editorial)
start_datestringNoWindow start, YYYY-MM-DD (inclusive). Omit for no lower bound.
topnumberNoHow many movers to return (default 20, max 100)

get_source_trend

How often the most-used sources were retrieved by AI answers over time, for a domain's prompts — the product's 'Source retrievals over time' chart on AI Visibility > Domains and URLs. Returns 'labels' (one per day, week or month) and 'series' (one per source, 'values' aligned to labels).

ParameterTypeRequiredDescription
domainstringYesBrand domain, e.g. acme.com
end_datestringNoWindow end, YYYY-MM-DD (inclusive). Omit for no upper bound.
grainstringNoTrend cited domains (default) or individual cited URLs One of: domain, url.
granularitystringNoBucket size (default day) One of: day, week, month.
start_datestringNoWindow start, YYYY-MM-DD (inclusive). Omit for no lower bound.

get_competitor_source_mix

For the domain's brand and each competitor, the share of AI-answer source retrievals that come from the brand's own site (owned), from third-party pages mentioning it (earned) and from everything else (other), measured across the domain's tracked prompts. Values are whole-number percentages that sum to 100 per brand (all three 0 means no retrievals).

ParameterTypeRequiredDescription
domainstringYesBrand domain, e.g. acme.com
competitor_domainsstring[]NoCompetitor domains to compare, overriding the saved tracked-competitor list. The brand itself is always included.
end_datestringNoWindow end, YYYY-MM-DD (inclusive). Omit for no upper bound.
start_datestringNoWindow start, YYYY-MM-DD (inclusive). Omit for no lower bound.

Site & Crawl Health

list_urls

Paged table of the brand's sitemap URLs (brand from your token), one row per URL combining three sources: Google indexing (index state, coverage detail, last Google crawl), AI-crawler reach (hit count and which bots fetched it) and the content audit (status, SEO score, entity score). Filters are ANDed; values inside one array filter are ORed.

ParameterTypeRequiredDescription
ai_crawledstringNoyes = fetched by at least one AI crawler; no = never One of: yes, no.
content_statusstring[]NoOnly URLs in any of these content-audit states: not_configured (not in the content report), queued (in the report, not scored yet), complete (scored), failed
google_crawledstringNoyes = Google has a last crawl time for the URL; no = not crawled yet One of: yes, no.
in_content_reportstringNoyes = the URL is in the content audit report One of: yes, no.
index_statestring[]NoOnly URLs in any of these Google index states
orderstringNoSort order (default asc) One of: asc, desc.
pagenumberNoPage number, 1-indexed (default 1)
page_sizenumberNoPage size (default 25, max 100)
searchstringNoSubstring match on URL or coverage detail
sort_bystringNoSort column (default: server order). 'crawled' sorts by AI-crawler hit count. One of: url, indexState, crawled, googleCrawled, contentStatus, seoScore, entityScore, lastCrawlTime, updatedAt.

get_url_details

Details for one URL of the brand on your token. Today this is the Google Search Console view: index state, coverage detail, whether crawling is allowed, last Google crawl, plus the raw URL Inspection result under 'raw' (verdict, robots/canonical/mobile details as Google returned them).

ParameterTypeRequiredDescription
urlstringYesFull page URL exactly as listed by list_urls

get_url_funnel

URL funnel for the brand on your token, as on the AI Visibility > URLs page: sitemap URLs → crawled by Google → indexed by Google, plus an aiReach band (sitemap URLs an AI crawler actually fetched vs. not).

No input parameters required.

get_search_console_status

Google Search Console connection and sync state for the brand on your token: whether it's connected, the selected property, the brand's configured domain and whether the property matches it, the connected Google account, last poll time, the sync schedule (last/next run, cadence, tier) and any in-flight sync run (queued | running | paused, with resumesAt when paused).

No input parameters required.

get_technical_recommendations

Technical AI-crawlability and on-page/entity-signal recommendations for a domain's most recent completed audit — matching the product's AI Visibility > Technical group (Crawl Insights, Content & SEO, Entity Signals tabs). Distinct from get_owned_content_recommendations/get_earned_content_recommendations, which are citation-gap content ideas, not technical checks.

ParameterTypeRequiredDescription
domainstringYesDomain to fetch technical recommendations for
page_urlstringNoScope page_recommendations to a single page URL. Omit to get every audited page's recommendations.
statusstringNoFilter both sections to items with this status: PASS | WARN | FAIL

Prompt Research

list_prompt_research

Lists a brand's prompt research sessions: each is a run that discovers the questions buyers ask AI about the brand's category, from which the user picks prompts to track.

ParameterTypeRequiredDescription
domainstringYesBrand domain whose prompt research to list, e.g. acme.com

get_prompt_research

Returns one prompt research session's researched prompts and personas. Each prompt has prompt_text, topic, persona, branding (branded or non-branded), intent (informational, commercial or transactional), country, language, recommended and tracked. Prompts are grouped either by topic or by persona. Get the id from list_prompt_research.

ParameterTypeRequiredDescription
domainstringYesBrand domain the research belongs to, e.g. acme.com
idstringYesResearch id from list_prompt_research
group_bystringNoHow to group prompts: topic (default) or persona
tracked_onlybooleanNoIf true, return only prompts already tracked

Recommendations

get_owned_content_recommendations

Lists content recommendations for the brand's own site (channel_type onsite): content to publish on your blog or site to close the AI-citation gaps found in probing. Each item includes severity_tier, gap_score, our_citations and total_citations, and competitors_winning as evidence.

ParameterTypeRequiredDescription
domainstringYesDomain to fetch owned content recommendations for
channelstringNoFilter by channel, e.g. Blog
limitnumberNoMax results per page (default 25, max 100)
offsetnumberNoResults to skip (default 0)
prioritystringNoFilter by priority: HIGH | MED | LOW
statusstringNoFilter by status: suggested | todo | approved | dismissed (default: all active statuses, dismissed excluded)

get_earned_content_recommendations

Lists content recommendations for earned, third-party media (channel_type earned): ideas for getting cited on sites such as Reddit, G2 or other reference and editorial domains.

ParameterTypeRequiredDescription
domainstringYesDomain to fetch earned content recommendations for
channelstringNoFilter by channel, e.g. Reddit, G2
limitnumberNoMax results per page (default 25, max 100)
offsetnumberNoResults to skip (default 0)
prioritystringNoFilter by priority: HIGH | MED | LOW
statusstringNoFilter by status: suggested | todo | approved | dismissed (default: all active statuses, dismissed excluded)

get_ad_recommendations

Lists ChatGPT Ads plays for a domain: auction-gap recommendations matching the AI Visibility Recommendations > Ads tab in the product.

ParameterTypeRequiredDescription
domainstringYesDomain to fetch ChatGPT Ads recommendations for
limitnumberNoMax results per page (default 25, max 100)
offsetnumberNoResults to skip (default 0)
play_typestringNoFilter by play type: Defend brand | Enter auction | Expand coverage | Refresh creative | Topic entry
prioritystringNoFilter by priority: HIGH | MED | LOW
statusstringNoFilter by status: suggested | todo | approved | dismissed (default: all active statuses, dismissed excluded)

Drafting & Saving

generate_content_outline

Generates a content outline (structure only, not finished copy) for one owned-media content recommendation: headings, an answer-first opening summary, FAQ questions, and suggested schema markup types. The outline is generated on request and nothing is saved; calling it again produces a new one.

ParameterTypeRequiredDescription
content_typestringYesOwned-media content type — one of: Homepage, Domain, Product, Comparison, Article, Educational, Blog, Guide, How-to, Documentation, Listicle, Wiki
titlestringYesThe content recommendation's title to outline (e.g. from get_owned_content_recommendations)

generate_ad_creative_outline

Generates a ChatGPT Ads creative brief for one ads play: headlines, short body lines, calls to action, landing-page angle, differentiation from rivals, and related query themes. The brief is generated on request and nothing is saved; calling it again produces a new one.

ParameterTypeRequiredDescription
titlestringYesThe ads play title to brief (e.g. from get_ad_recommendations)
brandstringNoBrand display name for the creative (optional)
competitors_winningstring[]NoRivals currently winning the auction
domainstringNoBrand domain, e.g. acme.com. Optional; pass it when working across several brands so the brief is generated for the right one.
organic_gap_linkedbooleanNoTrue if this prompt also has an organic citation gap
our_ad_countnumberNoOur observed ChatGPT ad count on this prompt
play_typestringNoPlay type: Defend brand | Enter auction | Expand coverage | Refresh creative | Topic entry
rationalestringNoStrategic rationale from the recommendation
rival_ad_countnumberNoRival observed ChatGPT ad count on this prompt
topicstringNoTopic cluster for the play

save_content_recommendations

Saves content recommendations (owned and/or earned) to the brand's recommendations list as 'suggested' items for the team to act on. This is the only tool that writes data, and it is deliberately narrow: it creates new 'suggested' items or refreshes ones still 'suggested'.

ParameterTypeRequiredDescription
domainstringYesBrand domain the recommendations are for
recommendationsobject[]YesRecommendations to save (max 30)
probe_run_idstringNoThe probe run the evidence came from (run_id from get_citation_probe_data). Omit to use the latest run with results.

Diagnostics

check_connection

Confirms the ThriveStack connection is working and your sign-in was accepted. Returns the server time.

No input parameters required.
