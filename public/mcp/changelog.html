New tools are available on the ThriveStack MCP endpoint as soon as they are released. The directory listings (OpenAI, Claude and Cursor) pick up new tools after each platform reviews them, so a listing can show fewer tools than the endpoint.

Tool names link to the Tools Reference when the tool is documented there. All new tools are read-only except create_account_segment, which creates a segment.

Nov 3, 2026Improvements

Clearer results from existing tools

No new tools. These changes make results easier to read and to trust.

Changed
  • get_traffic_attribution_overview: the response now carries rows_note, which names any days that are in the totals but not in the rows. A partial first bucket is counted in totals only.
  • get_page_traffic, get_ai_crawl_summary, get_ai_crawl_urls and get_ai_revenue_pages: descriptions now say what is counted and what is left out. For example, page-level totals can sit a few percent below the channel-level overview, and the daily crawl chart covers only the five busiest bots.
  • get_cited_domains, get_url_report, get_owned_content_recommendations and get_earned_content_recommendations: a value outside an allowed list, such as an unknown sort, status or priority, now returns an error that lists the accepted values. Before, it was ignored or returned an empty list.
  • get_technical_recommendations: returns 2 pages by default (was 5), and leaves out the fixed explanation text unless include_explanations is true.
  • get_engine_visibility_trend, get_competitor_visibility and get_prompt_visibility_trend: dates are returned as YYYY-MM-DD, and trend granularity as day, week or month.
  • get_prompt_top_brands and get_prompt_metrics: descriptions now say which answers share of voice is measured across.
Nov 2, 20262 new tools

Page traffic and search performance

Two tools for a page-by-page view of a site: human visits from Google Analytics and clicks from Search Console.

Added · 2
  • get_page_trafficHuman visits per page, split into organic, direct, AI referral and other, with key events and the first and last day seen.
  • get_search_performanceSearch Console clicks, impressions, click-through rate and position per page.
Changed
  • list_urls: now lists the URLs known to the brand's Search Console sync, and adds AI-citation fields (cited, citedPromptCount, citedBy) and a cited filter. It no longer offers url as a sort column.
  • get_attribution_health: new coverage block that says what each source can tell you. Google Analytics is the only source of human visits; Cloudflare, Vercel and WordPress report AI bot requests only.
  • AI crawler tools: descriptions now say that hits are requests by AI bots, not human visits.
Oct 30, 20262 new tools

AI Visibility topics and run days

Two reads for prompt topics and probe history, plus accuracy fixes.

Added · 2
  • list_domain_topicsA brand's prompt topics, selected and suggested.
  • get_source_run_daysThe days a brand's prompts were run and their cited sources recorded.
Changed
  • get_probe_run: no longer returns internal cost and credit fields.
  • get_url_report and get_cited_domains: each metric (retrievals, retrieved_pct, retrieval_rate, citation_rate) is now defined, so a rate such as 1.82 is not read as a percentage.
  • get_competitor_visibility: share of voice is now worked out from each brand's mentions, in line with the Competitors page. Each brand reports its mentions and the basis used.
