Introduction

Connect AI assistants like Claude, Cursor, and other MCP-compatible tools to your ThriveStack AI Visibility data. Ask questions in plain language and get answers from the same data your dashboard shows.

MCP Server

Ask your AI assistant how AI search engines mention and cite your brand, how you compare with competitors, which pages and sources get cited, and what to publish next, with answers straight from your ThriveStack AI Visibility data. This works with Claude, Claude Code, Cursor, VS Code (GitHub Copilot), Windsurf, Gemini CLI, and any other MCP-compatible client.

What you can do

  • See how AI engines mention and cite your brand, and how that compares with your competitors over time
  • See which pages and sources AI answers retrieve and cite, and where your citations come from
  • Review the buyer questions being tracked for your brand, and explore prompt research to find new ones
  • Check your site’s crawl and indexing health, including Google Search Console state and AI-crawler reach
  • Get content, earned-media, technical and ChatGPT Ads recommendations, generate a content outline or ad creative brief for any of them, and save content recommendations to your brand
  • See which brands/products your ThriveStack account can access
  • Run the ai_visibility_analyst prompt for a structured, one-shot analysis instead of asking one question at a time

See Tools for the complete list of what’s available today.

How it works

Connect

Add the server URL to your AI tool. See our setup guide for your platform.

Authenticate

Sign in with OAuth (Claude, Claude Code, Cursor, VS Code and other clients that support it), or attach a Personal Access Token for clients that don’t. This only happens once.

Ask questions or run a prompt

Ask a free-form question, or invoke one of the built-in Prompts, or pick an idea from Use Cases.

Free-form questions:

  • “How visible is ourdomain.com in AI search compared with our top competitors?”
  • “Which buyer questions are we not being cited for, and who is cited instead?”
  • “What content should we publish to close our biggest citation gaps?”

Or pick a ready-made example from Prompts or Use Cases for a full analysis.

Connection details

Your tool may ask for these details:

Property Value
Server URL https://api.app.thrivestack.ai/mcp
Transport Streamable HTTP (Remote)
Authentication OAuth 2.1 (Claude, Claude Code, Cursor, VS Code and other clients that support it), or a Personal Access Token via Authorization: Bearer (any client)

Authentication

Two options, depending on what your client supports:

  • OAuth. Your AI assistant opens a ThriveStack consent page in your browser. Sign in and authorize access. The session persists across conversations. Available in every client that supports MCP OAuth, including Claude, Claude Code, Cursor and VS Code.
  • Personal Access Token. Generate one from Personal Access Tokens (AI Visibility → Settings → Personal Access Tokens) in the ThriveStack dashboard, then attach it as an Authorization: Bearer header on your client’s MCP connection. Use this for clients without OAuth support (for example Windsurf and Gemini CLI) and for headless or CI setups.

Either way, every call resolves your product and environment automatically and respects the same permissions as your dashboard session. See the setup guide for client-by-client examples.

Read and write access

All tools are read-only except one: save_content_recommendations saves content recommendations to your brand as suggested items for your team. It can only create new suggested items or refresh ones that are still suggested — it cannot approve, dismiss, assign or delete anything — and your AI client asks you to confirm before it runs. See Tools for the current list.

Supported platforms

The ThriveStack MCP works with any tool that supports MCP (Model Context Protocol). Setup guides:

  • Claude (Desktop & Web)
  • Claude Code (CLI)
  • Cursor
  • VS Code (GitHub Copilot)
  • Windsurf
  • Gemini CLI

OAuth is only implemented for Claude and Claude Code today — every other client connects with a Personal Access Token. See the setup guide.

Requirements

  • A ThriveStack account with API access
  • A supported AI tool
