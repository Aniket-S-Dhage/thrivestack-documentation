Tools Reference

The tools of the ThriveStack MCP Server for Revenue Intelligence, with parameters and what each one does.

This page documents 129 tools of the ThriveStack MCP Server for Revenue Intelligence: 4 for setup, 29 for revenue, 33 for marketing, 35 for product analytics and 28 for accounts.

128 of the 129 tools are read-only. The only tool here that changes anything is create_account_segment, which creates a saved account segment. It does not edit or delete anything else.

None of these tools take a domain, project_id or similar tenant parameter. Your product and environment are resolved automatically from how you authenticated (OAuth session or Personal Access Token) — see Setup.

Your AI assistant calls these automatically based on your questions. Each section opens with an Example prompts dropdown, with a sample question for every tool in it. The server does not ship a native MCP prompt for Revenue Intelligence; see Prompts for copy-ready ones. It does not expose any MCP resources.

Response format

There is no single universal response envelope — each tool returns the JSON shape natural to its own data.

  • Money: amounts are in your brand’s base currency, named in the currency field of the result. Where a tool also returns an original amount, it carries its own currency.
  • Windows: revenue tools with a time_period accept THIS_MONTH, LAST_MONTH, LAST_3_MONTHS, LAST_6_MONTHS, THIS_YEAR, LAST_YEAR or ALL_TIME (default LAST_6_MONTHS, complete months). Marketing and account tools take a time_range such as 7d, 30d or 90d. A few product tools take a month as YYYY-MM.
  • Paging: list tools take limit and offset, or page and page_size. Large results are paged, so ask for the next page when you need more rows.
  • Metric tools: the tools whose names start with get followed by a capital letter (for example getMonthlyActiveUsers) each return one metric. You choose a template for the shape: a single value, a change, or a series.
  • Interactive tools: a few tools work in steps, such as a ranking you can drill into. The step parameter says which step to run, and your assistant carries the ids from one step to the next.
